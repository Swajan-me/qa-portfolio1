# QA Automation Suite

Automated tests for a demo e-commerce app built as part of my QA learning.

**Tools:** Playwright, Postman, GitHub Actions

## What is tested

- Login — valid, invalid, empty fields, locked account
- Cart — adding items, badge count, empty cart
- Checkout — form validation, order completion

## How to run

npm install
npx playwright install chromium
npx playwright test
